# The Crzy Journey

This is the recreated project structure.

## Folder structure

- assets/
  - backgrounds/  - menu/game backgrounds
  - images/       - UI and miscellaneous images
  - sprites/      - player/enemy/game sprites
  - audio/music/  - music
  - audio/sfx/    - sound effects
  - fonts/        - custom fonts
  - data/         - JSON/data files
- css/             - stylesheets
- js/              - JavaScript
- levels/          - level data
- saves/           - save-related files

## Important

The original image/audio/sprite assets from your old PC project are not available in this conversation, so they cannot be magically reconstructed. The folders are included and ready for you to drop those assets back into.

Open `index.html` through your local web server (recommended) rather than relying on file:// if your JavaScript uses module/fetch loading.
